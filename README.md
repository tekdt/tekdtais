## Usage Instructions

Simply select the software you want to download and press the **Download** button, or press **Add** to put it into the queue for batch installation, then press **Start** to install everything in one go.  
If you prefer command-line mode, type `TekDT_AIS.exe /help` for more commands and guidance.

This software is also embedded (as a component) in **TekDT BMC** ([https://github.com/tekdt/tekdtbmc](https://github.com/tekdt/tekdtbmc)) and **SEZOY** (a closed‑source upgraded version of TekDT BMC that provides more professional network boot deployment). It is used to synchronize Windows installation and software deployment. TekDT BMC/SEZOY will automatically include this tool when creating USB Boot / PXE BOOT / HTTP(S) BOOT media – you do not need to do anything extra, except selecting the required software in the final step of TekDT BMC/SEZOY.

## Note

This program requires an internet connection for its first run, because it needs to download additional tools into the `Tools` folder (e.g., 7z, aria2). If you want to download new software, an internet connection is also required. However, if you have already downloaded some (or all) of the software you need, you can use it offline afterwards.
